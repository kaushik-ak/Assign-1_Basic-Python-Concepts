TASK 1

Functionality of the Program

Takes user input

a = eval(input("Enter the First No. :- "))
b = eval(input("Enter the Second No. :- "))


The program asks the user to enter two numbers.

These values are stored in variables a and b.

eval() converts the input into a number (like int or float) and also allows mathematical expressions.

Performs arithmetic operations

print("\nAddition :- ", a+b)
print("Subtraction :- ", a-b)
print("Multiplication :- ", a*b)
print("Division :- ", a/b)


Using the two numbers, the program calculates:

Addition of a and b

Subtraction of b from a

Multiplication of a and b

Division of a by b
